# CreamyDreams Cake website

This is a simple, beautiful one-page bakery website.

## Open and run it in VS Code

1. In VS Code, choose **File → Open Folder** and select this folder.
2. Open `index.html`.
3. Install the **Live Server** extension in VS Code, then click **Go Live** in the bottom-right corner.

You can also simply double-click `index.html` to view the site in a browser.

## Personalising it

- Replace the sample cake photos in `index.html` with the baker's own photo links.
- Use **Add menu media** on the website to preview menu images and videos while the page is open.
- Add the real WhatsApp, Instagram, email address, and order-processing service when available.

The on-page uploads are previews only; they do not permanently store images after the browser closes. Permanent uploads need a hosting/storage service (for example, Cloudinary or Supabase).
